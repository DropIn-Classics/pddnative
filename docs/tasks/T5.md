# T5: table-program data files

Branch `sol/T5-pdfiles`. Files: `tools/pdfiles.py`, this notes file.

Work started from master. The tool will parse and re-encode every
TBLDETLO/TBLDETHI collision map, render false-colour PNG previews, and
decode the PD/PD2 high-score files and DDPCOPTN.BIN according to the
formats documented in `src/PD.hints`.

## Tool

`tools/pdfiles.py` has three subcommands:

- `map FILE [--png OUT]` decodes all 512 rows and their two x halves,
  prints counts by surface and the event/code counts for surface 1Fh,
  re-encodes the records and requires byte-for-byte identity. The PNG
  is a 320x512 standard-library RGB image with one colour per surface.
- `hiscores FILE` prints the four ranked entries for each of the four
  tables. Each entry is three initials and six big-endian packed-BCD
  bytes (twelve decimal digits).
- `options FILE` prints the four choices, four key-map words and screen
  byte. A key word stores the byte index first and the one-bit mask
  second; the tool also prints the resulting scan code.

## High scores and options

Both 144-byte HISCORES files print four plausible ranked scores for all
eight tables. PD1 contains shipped entries with blank initials and
scores 18634310 (Steel Wheel) and 5700000 (Beat Box); the remaining
initials identify their tables. All score bytes are valid packed BCD.

The CD has no DDPCOPTN.BIN because the menu creates it. The options
decoder was checked with the menu's defaults from CODE:2BEB: it reports
three balls, game-controlled music, colour, gravity 9, Left Shift,
Right Shift, Space, E0 Down and 320x200.

## Difference from `PD.hints`

The hints call DDPCOPTN.BIN 14 bytes and describe `opt_screen` as a
word. DDPCMAIN's `load_options` at CODE:2BEB requires a 13-byte file and
`save_options` at CODE:2CFE writes 0Dh bytes: four choice bytes, four
key words and one resolution byte. `pdfiles.py` follows that writer.
PD.EXE loads the byte at DATA:9AA2; the following byte is merely the
zeroed storage beside it. No map or high-score file disagreed with the
comments in `PD.hints`.
